
# Оптимизация размещения контейнеров на судне

Дипломный проект студента Санкт-Петербургского государственного морского технического университета. Разработка ПО для оптимизации размещения контейнеров с учётом остойчивости и минимизации перевалок.

## Статус

В разработке. Локально реализованы доменная модель, загрузчик конфигураций и математическое ядро T06–T08: масса и центр тяжести, гидростатика, крен, дифферент и проверка допустимости плана размещения.

Программа остаётся учебным прототипом для синтетического судна. Расчёт R, декодер, оптимизация и пользовательский интерфейс ещё не реализованы; новый генератор T03 также не завершён. Подробный актуальный статус, сведения о тестах и публикации находятся в [docs/state.md](docs/state.md).

## Стек

- Python 3.13, NumPy, Pandas, Matplotlib
- pymoo (NSGA-II) — оптимизация
- Flask + SQLite — веб-интерфейс и база данных
- pytest — автоматические тесты

## Структура

- `src/stowage/` — основной код
- `configs/` — параметры судна, ограничений и портов
- `data/` — входные данные
- `docs/` — математическая модель, решения и состояние проекта
- `tests/` — автоматические тесты
- `results/` — результаты визуализации и экспериментов

## Прогресс

История выполненных работ ведётся в [PROGRESS.md](PROGRESS.md), текущий план — в [docs/state.md](docs/state.md). Содержание T09 и индивидуальный реестр T09–T29 пока не подтверждены; расчёт R не назначен T09 автоматически.
