# Оптимизация размещения контейнеров на судне

Дипломный проект студента СПбГМТУ. Разработка ПО для оптимизации размещения 
контейнеров с учётом остойчивости и минимизации перевалок.

## Статус
В разработке. Фаза 0: окружение и структура.

## Стек
- Python 3.13, NumPy, Pandas, Matplotlib
- pymoo (NSGA-II) — оптимизация
- Flask + SQLite — веб и БД
- pytest — тесты

## Структура
- `src/stowage/` — основной код
- `configs/` — параметры судна, ограничений, портов
- `docs/` — model.md, decisions.md, state.md
- `tests/` — тесты
- `experiments/` — эксперименты и результаты
