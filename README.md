
# Оптимизация размещения контейнеров на судне

Дипломный проект студента Санкт-Петербургского государственного морского технического университета. Разработка ПО для оптимизации размещения контейнеров с учётом остойчивости и минимизации перевалок.

## Статус

В разработке. Выполнены **T01, T02, T04A и T04B**: подготовлены окружение и доменная модель из шести сущностей, JSON-конфигурации и загрузчик. **Следующий приоритет — T05**, формализация математической модели для согласования с руководителем. **T03 (генератор данных) отложена до завершения T05**.

## Стек

- Python 3.13, NumPy, Pandas, Matplotlib
- pymoo (NSGA-II) — оптимизация
- Flask + SQLite — веб-интерфейс и база данных
- pytest — автоматические тесты

## Структура

- `src/stowage/` — основной код
- `configs/` — параметры судна, ограничений и портов
- `data/` — входные данные
- `docs/` — математическая модель, решения и состояние проекта
- `tests/` — автоматические тесты
- `results/` — результаты визуализации и экспериментов

## Прогресс

- [x] T01 — Подготовка окружения
- [x] T02 — Доменная модель: 6 сущностей, тесты и аудит A/B/C/D
- [x] T04A — JSON-конфигурации
- [x] T04B — Загрузчик и проверка конфигурации

- [ ] T11–T17 — Алгоритмы размещения и оптимизации
- [ ] T18–T20 — База данных
- [ ] T21–T22 — Визуализация
- [ ] T23–T26 — Веб-интерфейс
