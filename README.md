# Оптимизация размещения контейнеров на судне

Дипломный проект студента Санкт-Петербургского государственного морского технического университета. Программа формирует и сравнивает планы размещения контейнеров с учётом остойчивости, ограничений загрузки и порядка выгрузки в портах.

## Статус

Реализован вычислительный прототип для синтетического прямоугольного судна типа `box-barge`:

- доменные сущности контейнера, слота, судна, маршрута и плана;
- загрузка и проверка JSON-конфигураций;
- расчёт массы, центра тяжести, осадки, GM, крена и дифферента;
- проверка полноты размещения, опоры, массы и нагрузок;
- подсчёт потенциальных блокирующих пар `R`;
- детерминированный декодер перестановки контейнеров;
- базовая эвристика и многокритериальный поиск NSGA-II из `pymoo`;
- 2D-схемы загрузки, графики наблюдаемого фронта Парето и воспроизводимые эксперименты.

Прототип проверяет исходное состояние загрузки. Он не моделирует реальные портовые операции, остойчивость после последовательных выгрузок и не является сертифицированной системой проверки безопасности судна. Новый генератор данных T03, SQLite, прикладные сервисы и веб-интерфейс пока не реализованы.

Подробный актуальный статус находится в [docs/state.md](docs/state.md), а последовательное учебное объяснение проекта — в [docs/internal/walkthrough.md](docs/internal/walkthrough.md).

## Стек

- Python 3.13;
- NumPy, Pandas и Matplotlib;
- pymoo с алгоритмом NSGA-II;
- pytest;
- Flask и SQLite утверждены для будущих слоёв интерфейса и хранения.

## Структура

- `src/stowage/domain/` — контейнеры, судно, слоты, маршрут и план;
- `src/stowage/config/` — загрузка и проверка конфигураций;
- `src/stowage/model/` — физические расчёты, ограничения и оценка плана;
- `src/stowage/algorithms/` — декодер, эвристика, постановка pymoo и NSGA-II;
- `src/stowage/viz/` — схемы загрузки и графики;
- `experiments/` — воспроизводимые исследовательские и демонстрационные сценарии;
- `configs/` — параметры судна, ограничений и маршрута;
- `data/` — входные данные;
- `tests/` — автоматические тесты;
- `results/` — сохранённые таблицы, манифесты и PNG.

Каталоги `datagen/`, `storage/`, `services/` и `web/` пока являются архитектурными заготовками.

## Окружение

Используется существующее виртуальное окружение проекта на Windows 11. Из корня репозитория:

```powershell
.\.venv\Scripts\python.exe -m pip install -e .
```

Не создавайте новое окружение без отдельного решения проекта.

## Тесты

Полный набор запускается существующим Python проекта:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Фактический результат последнего подтверждённого запуска указывается в [docs/state.md](docs/state.md). Успешные тесты подтверждают согласованность реализации с принятыми примерами, но не инженерную применимость модели к реальному судну.

## Демонстрация преподавателю

Живой запуск эвристики, NSGA-II и отдельного GM-контроля:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m experiments.demo_for_advisor
```

Флаг `--open-plots` открывает изображения после расчёта. Резервный режим восстанавливает опубликованные планы seed 42, заново оценивает их тем же ядром и повторяет малый перебор GM:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m experiments.demo_for_advisor --saved
```

Пошаговый сценарий показа находится в [results/demo_for_advisor/README.md](results/demo_for_advisor/README.md).
