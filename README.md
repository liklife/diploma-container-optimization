
# Оптимизация размещения контейнеров на судне

Дипломный проект студента Санкт-Петербургского государственного морского технического университета. Разработка ПО для оптимизации размещения контейнеров с учётом остойчивости и минимизации перевалок.

## Статус

В разработке. Выполнены T01, T02, T04A, T04B и T05: подготовлены окружение и доменная модель, JSON-конфигурации и загрузчик, формализована математическая модель. Добавлен параметр `max_draft_m`, завершена уборка старых файлов в `legacy/`. T03 — безопасный воспроизводимый генератор тестовых данных — остаётся отдельной задачей. **Следующий этап — T06**, расчёт массы и центра тяжести системы «судно — груз».

## Стек

- Python 3.13, NumPy, Pandas, Matplotlib
- pymoo (NSGA-II) — оптимизация
- Flask + SQLite — веб-интерфейс и база данных
- pytest — автоматические тесты

## Структура

- `src/stowage/` — основной код
- `configs/` — параметры судна, ограничений и портов
- `data/` — входные данные
- `docs/` — математическая модель, решения и состояние проекта
- `tests/` — автоматические тесты
- `results/` — результаты визуализации и экспериментов
