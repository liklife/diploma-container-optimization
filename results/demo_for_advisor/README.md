# Демонстрация преподавателю · 25 ноября 2026

Запустите из корня репозитория в PowerShell.

```powershell
.\.venv\Scripts\python.exe -X utf8 -m experiments.demo_for_advisor
```

Команда выполняет поиск и печатает пути к PNG. Чтобы открыть изображения сразу по завершении, добавьте `--open-plots`. Для управляемого показа удобнее открывать их по одному в порядке ниже. Схема эвристики и график GM используются по исходным путям. График Парето и схема NSGA-II для текущего запуска сохраняются рядом с этой инструкцией.

Если живой запуск NSGA-II недоступен, используйте резервную команду. Она восстанавливает планы эвристики и seed 42 из опубликованных таблиц, повторно оценивает их и заново выполняет малый перебор GM. Время поиска берётся из таблицы предыдущих измерений.

```powershell
.\.venv\Scripts\python.exe -X utf8 -m experiments.demo_for_advisor --saved
```
